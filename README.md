# second-brain-plugin

A Claude Code plugin for maintaining a persistent, compounding knowledge base — inspired by Andrej Karpathy's LLM Wiki. The LLM maintains your wiki; you direct it. Knowledge compounds across sessions, projects, and contexts.

## Installation

```bash
claude plugin add github.com/YOUR_ORG/second-brain-plugin
```

## Commands

| Command | Description |
|---------|-------------|
| `/second-brain init` | Initialize a new second-brain (personal or team mode) |
| `/second-brain ingest` | Ingest raw sources into structured wiki pages |
| `/second-brain query` | Query the knowledge base with natural language |
| `/second-brain lint` | Validate pages for schema compliance, staleness, and broken links |
